## Sticky Todo 0.3.0

### 새로 생긴 것
- **내 그림으로 꾸미기 (테마)**: ☰ → 설정 → 테마에서 고정 핀, 체크·완료 아이콘, 추가 버튼, 오늘 표시, 배경을 내 그림으로 바꿀 수 있어요. 처음이라면 예시 테마 **귤 친구**를 눌러 보세요.
- **테마 파일 (.stodotheme)**: 만든 테마를 파일 하나로 저장해서 친구에게 줄 수 있어요. 받은 파일은 **테마 불러오기…** 를 누르거나 노트 위로 끌어다 놓으면 미리보기로 열려요. 설정 창에서 **확인**을 눌러야 저장돼요.
- **공휴일 표시**: 2026~2028년 대한민국 공휴일을 월간 달력에는 빨간 숫자로, 주간·하루 보기에는 이름 배지로 보여줘요. 2028년은 아직 공식 확정 전이라 바뀔 수 있어요.
- **글자 꾸미기**: `**굵게**`, `*기울임*`, `~~취소선~~`, `__밑줄__`. 입력칸에서 Ctrl+B / I / U로도 할 수 있어요.
- **날짜 고르기**: 할 일을 우클릭 → **날짜 고르기…** 로 달력에서 아무 날짜나 골라 옮길 수 있어요 (노트, 전체 목록 둘 다). 전체 목록에서는 오늘·내일·모레·다음 주 월요일로 바로 옮길 수도 있어요.
- **새 버전 알림**: 하루 한 번 새 버전이 나왔는지 확인하고 알려줘요. ☰ → 업데이트 확인으로 바로 확인할 수도 있고, 설정에서 끌 수 있어요.

### 고친 것
- 전체 목록에서 여러 개를 선택한 뒤 우클릭하면 하나만 선택되던 문제를 고쳤어요.
